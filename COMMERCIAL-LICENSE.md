# Proxima EDU — Commercial License

The Proxima **EDU Edition** is commercial software offered under a separate
license agreement from Conzex Global Private Limited.

## What it is

Organization-scale features for running Proxima in education and training:

- Organizations, classes/cohorts, and instructor / TA roles
- Roster import (CSV, LDAP / Active Directory, SCIM) and domain-locked bulk invites
- Directory / SSO provisioning and sync
- End-of-term teardown automation and idle reclamation
- Per-class usage reporting

## How it's licensed
